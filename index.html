samos

Ansible playbooks for a Framework 13 laptop (AMD Ryzen AI 300) running CachyOS for gaming, local AI and a small service stack.

Repository Playbooks

Hardware

Machinesamos, Framework 13
Memory96 GB
CPU / NPUAMD Ryzen AI 300 series with XDNA NPU
Graphicsintegrated Radeon, large shared memory allocation for models
SystemCachyOS, systemd-boot

What it sets up

  • Base: keyrings, upgrade, users, Neovim as editor
  • Kernel: linux-cachyos, AMD microcode, amd_pstate and boot options
  • Gaming: kernel options for games (pci=rebar, split_lock_detect=off); the machine also runs Steam and Microsoft Flight Simulator 2024.
  • AI: ROCm, the XDNA NPU driver, Lemonade server with embedding and reranker models
  • Services: Docker, local root CA, Traefik, Caddy, Elasticsearch and Kibana, Homepage
  • Desktop: Flatpak, Google Chrome, Firestorm viewer (Second Life), Java language server

Every setup playbook has a teardown.

Usage

./ansible-user-setup.yml -K     # create the ansible user (needs your sudo password)
./setup.yml                     # run every setup playbook
./teardown.yml                  # revert it
